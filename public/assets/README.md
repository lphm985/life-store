# Thư mục lưu trữ Assets của Game

Các file ảnh (PNG, WEBP, SVG, GIF) đặt tại đây sẽ được Next.js phục vụ trực tiếp qua đường dẫn: `/assets/...`

## Phân loại thư mục:
- `/assets/crops/`: Ảnh cây trồng, giai đoạn trưởng thành hoặc nông sản (VD: `wheat.png`, `carrot.png`, `tomato.png`).
- `/assets/seeds/`: Ảnh các gói hạt giống (VD: `seed_wheat.png`, `seed_carrot.png`).
- `/assets/foods/`: Ảnh món ăn chế biến từ bếp (VD: `bread.png`, `salad.png`).
- `/assets/minions/`: Avatar, nhân vật nhân viên RPG (VD: `warrior.png`, `miner.png`).
- `/assets/icons/`: Các icon UI tài nguyên game (VD: `gold.png`, `gem.png`, `energy.png`).
